# Thaumic Horizons: Reforged

Неофициальный перенос Thaumic Horizons для Minecraft 1.21.1 / NeoForge. Алхимия, медицина, души, чаны, големы и карманные миры работают через расширения нашего Thaumcraft 4: Reforged.

Текущий выпуск: **1.0.4**.

## Для запуска

Нужны **Minecraft 1.21.1**, **Java 21** и **NeoForge 21.1**; общая сборка проверена на **21.1.264**.

- [Наш Thaumcraft 4: Reforged1.0.1](https://github.com/yzs57phbts-web/thaumcraft-4-reforged-dop/releases/tag/1.0.1).
- [Curios API 9.5.1](https://www.curseforge.com/minecraft/mc-mods/curios/files/6529130) и [TerraBlender 4.1.0.1+ для NeoForge](https://www.curseforge.com/minecraft/mc-mods/terrablender-neoforge/files/6054947) — зависимости ядра T4. Для совместных проверок использовался TerraBlender 4.1.0.8.
- Другие аддоны T4 не обязательны для базового запуска. Для дополнительных интеграций используются совместимые версии из той же сборки.

Скачайте JAR из [релиза 1.0.4](https://github.com/yzs57phbts-web/thaumic-horizons-reforged/releases/tag/1.21.1-v1.0.4) и положите в `mods` вместе с зависимостями. В папке должна быть одна версия каждого мода.

Ниже перечислены **отличия относительно исходника**: Thaumic Horizons для Minecraft 1.7.10 из сохранённого эталона проекта. Исходные предметы и механики сами по себе не считаются добавлениями этой версии.

## Пофиксили

- Исправлены возникшие при переносе зарядка, слоты боезапаса и синхронизация инъектора.
- Исправлены плавание таумиевой лодки по лаве и состояние огнестойкости.
- Исправлены продолжение партий сита в кузне души и возобновление питания Cognitio.
- Инвентари инъектора и футляра блокируют перемещение удерживаемого контейнера; сохранение существ/генетики защищено от дублирования.

## Адаптировали

- Числовые ID измерений и эффектов заменены именованными реестрами 1.21.1.
- Чаны, големы, печные бонусы и форматированные страницы подключены к расширениям нашего T4.
- Карманные миры и незавершённая генерация сохраняются средствами современного сервера.
- Врата подготавливают безопасный выход с учётом габаритов современного игрока.

## Изменили

- Лодки используют современную геометрию и вёсла вместо старой модели 1.7.10.
- Инъектор использует современную геометрию арбалета с собственной палитрой; цвет инъекций определяется их составом.
- Клиентские эффекты и постепенное появление клона реализованы средствами нового движка; покадровая идентичность 1.7.10 не заявляется.

## Совместимость и проверки

Выпуск рассчитан на API нашей доработанной версии T4. Совместимость с чистым авторским T4 автоматически не предполагается.

Опубликованный JAR совпадает по SHA256 с выбранным установленным выпуском. Эта комбинация участвовала в проверке полной сборки: загрузка, настоящий Creative-мир, вкладка T4, прокрутка предметов и повтор после перезагрузки ресурсов. Это не означает полного прохождения всех механик каждого аддона. Подробности текущего выпуска и ограничения сохранены в исходниках/уведомлениях проекта; старые отчёты относятся к своим версиям.

## Сборка из исходников

Положите наш T4, Curios 9.5.1 и TerraBlender 4.1.0.8 в `libs/`. Путь T4 можно задать через `-PcoreJar=/путь/к/T4.jar`, папку зависимостей — `-PmodsDir=/путь/к/libs`.

```sh
./gradlew build
```

Старые GameTest-классы отделены от обычной сборки. `compileGameTestJava` компилирует их отдельно, `runGameTestServer` подключает их только в тестовом запуске. Вспомогательный игрок взят из исходников нашей базы T4.

Нужен JDK 21. Машинные пути разработчика, эталонные сторонние JAR, игровые миры и конфиги профиля в репозиторий не включены. Скомпилированный выпуск находится в GitHub Releases; `SHA256SUMS.txt` позволяет проверить скачивание.
